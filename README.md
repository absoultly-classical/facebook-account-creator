# Facebook Account Creator

## Configuration

Copy `.env.example` to `.env` and set values for integrations you use. Do not commit `.env`, credential files, session data, or generated results.

## Setup

Install Node.js and Chrome/Chromium, then run `npm ci`. Set the required environment variables in your shell and run `node register-loop.js`. Use `npm test` to check JavaScript syntax.
